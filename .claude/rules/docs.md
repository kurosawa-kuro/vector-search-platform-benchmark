# ドキュメントルール

- ドキュメントの入口は `docs/00_index.md` を使う。
- 正本の定義を複数ファイルに重複させない。
- 秘密情報や実在する個人・プロジェクトデータを書かない。
- 挙動の変更と同じ変更内でドキュメントも更新する。

## 図版（draw.io）

- 図の正本は `docs/図版/*.drawio`（非圧縮 XML・1 ファイル 1 主題）。書き出した PNG / SVG を正本にしない。
- 作成・編集は draw.io MCP（`.mcp.json` の `drawio`）を使う。既存ファイルは `list_pages` → `get_page` → `set_page` で該当ページだけ差し替え、ファイル全体を手書きで上書きしない。
- 新規・下書きは `open_drawio_mermaid` / `open_drawio_csv` / `open_drawio_xml` でエディタに出して形を決めてから `docs/図版/` に保存する。
- 図は本文の代わりにならない。構成要素・境界の定義は `docs/02_architecture.md` が正本で、図はその参照先として置く（定義を二重化しない）。
- `.drawio` の差分は読みにくいため、図を変えたら対応する本文側の記述も同じ変更で直す。
